# Quantum Lab

Laboratório interativo de computação quântica com Qiskit Aer e Streamlit.

## Requisitos

- Windows 10/11, Linux ou macOS
- Python 3.10 – 3.13
- Conexão Wi‑Fi (para acesso por celular)

## Instalação no Windows

1. Instale o Python 3.12 em https://www.python.org/downloads/ (marque “Add Python to PATH”).
2. Abra o Prompt de Comando na pasta do projeto.
3. Crie e ative um ambiente virtual:

   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   ```
